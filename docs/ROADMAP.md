# Spendly 개발 로드맵

최종 갱신일: 2026-10-21. 일정과 요구사항 기준: [PROJECT_SPEC](PROJECT_SPEC.md). 1인·주 15~20시간·6주(90~120시간) 계획이며 실제 착수일과 달력상 마감일은 미정이다.

## 갱신 규칙
- 완료·진행 중·예정으로 구분한다. 새로운 Codex 스레드에서도 문서와 실제 코드를 대조한다.
- 착수 시 진행 중으로 이동하고 시작일·범위·차단 사항을 기록한다. 구현 및 필요한 검증을 마친 뒤에만 완료로 이동하고 날짜·파일·테스트 결과를 남긴다.
- 개발 진행에 따라 같은 작업에서 갱신한다. 문서 정리 완료를 서비스 구현 완료로 기록하지 않는다.
- 설계 변경이 확정되면 PROJECT_SPEC과 관련 PRD·아키텍처·DB·API 문서를 함께 갱신하고 변경 이유·날짜를 기록한다.
