# Spendly 개발 로드맵

최종 갱신일: 2026-10-20. 일정과 요구사항 기준: [PROJECT_SPEC](PROJECT_SPEC.md). 1인·주 15~20시간·6주(90~120시간) 계획이며 실제 착수일과 달력상 마감일은 미정이다.

## 갱신 규칙
- 완료·진행 중·예정으로 구분한다. 새로운 Codex 스레드에서도 문서와 실제 코드를 대조한다.
- 착수 시 진행 중으로 이동하고 시작일·범위·차단 사항을 기록한다. 구현 및 필요한 검증을 마친 뒤에만 완료로 이동하고 날짜·파일·테스트 결과를 남긴다.
- 개발 진행에 따라 같은 작업에서 갱신한다. 문서 정리 완료를 서비스 구현 완료로 기록하지 않는다.
- 설계 변경이 확정되면 PROJECT_SPEC과 관련 PRD·아키텍처·DB·API 문서를 함께 갱신하고 변경 이유·날짜를 기록한다.

V2 적용·컨텍스트 테스트・서버 재시작 검증 완료: 로컬 테스트 XML(2026-10-20 19:12、1건・실패/오류 0)에 V2 최초 적용이 기록되고, 사용자 제공 19:13 서버 로그에 2개 마이그레이션 검증・현재 버전 2・추가 적용 없음・8080 정상 기동이 기록됐다. 제약조건 검증 SQL 실행 결과만 대기다. Codex에서 테스트를 직접 재실행한 결과는 아니다.
  - `backend/src/test/resources/db/verify_categories.sql` 작성: 기본값, 사용자·유형별 동일 이름 허용, 영문 대소문자 구분, 보관 후 중복 차단, 유형·빈 이름 CHECK, 사용자 FK·삭제 RESTRICT를 검증하고 fixture는 롤백한다. Gradle이 자동 실행하는 테스트가 아니라 psql로 별도 실행하는 SQL이다. 소스 작성·정적 대조·git diff --check는 통과했다. 별도 SQL 실행 결과는 아직 받지 못했으며, 컨텍스트 테스트 통과와 제약조건 검증 통과를 구분한다.
